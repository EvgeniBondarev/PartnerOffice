# Дизайн PartnerOffice

Визуальный язык кабинета партнёров: копия интерфейса «Турбо ПВЗ» (дизайн-система ozi), снятая 2026-10-12 (версия 3.11.59).

## Открыть брендбук

`brandbook/index.html`: двойной клик или `python3 -m http.server` из папки `design` и страница `/brandbook/index.html`. Страница самодостаточна: иконки встроены, стили подключены относительными путями.

Пересборка после правок токенов, иконок или компонентов:

```bash
python3 design/build/build_brandbook.py
```

## Состав

| Папка | Что внутри |
|---|---|
| `brandbook/` | Брендбук: цвет, типографика, сетка, иконки, каркас, 14 групп компонентов, шаблоны страниц, правила |
| `tokens/` | `ozon-tokens.css` и `.json`: 316 переменных `:root`, 173 светлой и 173 тёмной темы (`.theme-dark`) |
| `components/` | `base.css` (шрифт, сброс), `layout.css` (шапка, меню, страница, плитки, карточки), `dropdown.css`, `checkbox.css`, `calendar.css`, `demo.html` |
| `components/ozon/` | 25 файлов компонентов, автоматически выгруженных из оригинала (классы `ozi__X__y__HASH` → `po-X__y`) |
| `components/ozon/_full-reference/` | Полные выгрузки списка, календаря и чекбокса из оригинала для сверки |
| `fonts/` | Onest 2.0 (вариативный, OFL) |
| `icons/` | `icons.svg`: спрайт из 26 символов (24 снятых с оригинала + `ui-calendar`, `ui-close`, нарисованные вручную) |
| `build/` | Генератор брендбука |
| `reference/` | Скриншоты оригинала (36) и исходные CSS (86 файлов). **В git не входит** (`.gitignore`): на скриншотах реальные данные ПВЗ, CSS принадлежит Ozon |
| `RESEARCH.md` | Подробная сводка исследования |

## Порядок подключения

```html
<link rel="stylesheet" href="tokens/ozon-tokens.css">
<link rel="stylesheet" href="components/base.css">
<link rel="stylesheet" href="components/ozon/button.css">   <!-- нужные компоненты -->
<link rel="stylesheet" href="components/layout.css">
```

## Что заменить своим перед запуском

Логотип (в брендбуке заглушка «PO»), название «Турбо ПВЗ», 3D-иллюстрации и рекламные баннеры Ozon не переносились. Иконка-логотип Ozon оставлена в `icons.svg` как `logo-circle` только для справки, в интерфейс её выводить нельзя.

## Известные ограничения

- Тёмная тема: токены есть, страницы в ней не проверялись.
- Не снято: формы действий (выдача, приём), сообщения об ошибках при отправке, toast-уведомления, выбор месяца и года в календаре.
- Мобильные ширины (<900px) сверены только по media-запросам CSS.
- Информер использует свой значок «i» вместо картинки Ozon; плитки-хаб — иконки-заглушки вместо 3D-иллюстраций.
