# Исследование UI «Турбо ПВЗ» (turbo-pvz.ozon.ru) для PartnerOffice

Снято 2026-10-12 с `https://turbo-pvz.ozon.ru/receiving-v2/main` (версия 3.11.59), аккаунт под логином ПВЗ, только чтение. Разделы: Приёмка, Выдача заказов, Претензии.

## Что лежит в папке

- `tokens/ozon-tokens.css` и `tokens/ozon-tokens.json`: все дизайн-токены (root 316, light 173, dark 173).
- `fonts/Onest-2.0.woff2`: вариативный шрифт Onest, веса 100–900.
- `icons/icons.svg`: спрайт из 27 иконок меню и интерфейса (24px, `currentColor`).
- `reference/screenshots/`: 3 скриншота (приёмка, выдача, претензии).
- `reference/ozon-css-raw/`: исходные CSS страницы (64 файла) для сверки значений.

## Технологии оригинала

- Nuxt 3 (Vue 3), микрофронтенды (`data-micro-name`), CSS-модули.
- Дизайн-система `ozi` (классы `ozi__button__...`, `ozi-body-500`), тема переключается классом `.ozi__light__light__*` / `.ozi__dark__dark__*`. У `body[data-ozi-theme=dark]` есть тёмная тема.
- Типографика: шрифт `Onest`, запасные `Helvetica Neue, Helvetica, Arial, sans-serif`.

- Шапка: фикс, высота 56px, белая, паддинг 0 24px, нижняя линия `box-shadow: inset 0 -2px 0 #d9dde1`. Слева логотип (круг 32px, `#005BFF`) и «Турбо ПВЗ» (heading-300, 19px/600). Рядом селект пункта (320×32). Справа версия, два иконки-колокольчика со счётчиками, имя пользователя, аватар.
- Левое меню: ширина 260px (свёрнутое 88px), фон `--neutral-600 #203148`, паддинг 16px 16px 0, высота `100% − 56px`.
- Пункт меню: высота 44px, радиус 8px, иконка 24px слева, текст 14px/21px, цвет `--text-500-inverted #fffffff2`.
- Активный пункт: фон `--action-100 #2f9bf94d`, на hover `--action-50 #2f9bf91f`. Фокус: outline 2px `--action-400 #2f9bf9`.

Ширину окна Chrome инструмент менять не позволил, поэтому проверку на 1100 и 800px нужно повторить вручную.

## Что осталось неснятым

1. Тёмная тема: токены есть (`.theme-dark`), но включить её на странице переключением атрибута не получилось, внешний вид не снимался.
2. Не открывались действия, меняющие данные: оформление выдачи заказа, приём отправления, создание отчёта, начало инвентаризации. Их формы и сообщения об ошибках не сняты.
3. Состояния ошибок полей (красная рамка, подпись) и toast-уведомления: для их показа нужно отправить некорректный ввод.
4. Иконка QR-скана в шапке страницы и несколько иконок в нижней части меню не выгружены полностью (в `icons.svg` помечено). Иллюстрации и баннеры не копировались намеренно.
5. Страницы с данными вне вашего пункта, детальные карточки (отправление, претензия), печатные формы (`@media print`).

## Юридические замечания

- Название «Озон», логотип, 3D-иллюстрации и баннеры принадлежат Ozon. Перенос стиля 1:1 допустим для внутреннего удобства, но логотип, иллюстрации и название «Турбо ПВЗ» в PartnerOffice лучше заменить собственными: у партнёров не должно возникать впечатления, что это продукт Ozon.
- Шрифт Onest: открытая лицензия SIL OFL, можно использовать и распространять.


## Компоненты в коде (`components/`)

Готовые стили, снятые с оригинала и проверенные в браузере сравнением со скриншотами; использовать вместе с `tokens/ozon-tokens.css`.

- `components/dropdown.css`: список (`po-dropdown`), пункт (`po-dropdown-item`), группа, пустой список и поле селекта с плавающей подписью (`po-select`). Пункт 44px (padding 10/12, gap 8px), поле списка padding 8px, hover `rgba(171,188,213,.118)`, поле в фокусе `inset 2px #005bff`; при выборе подпись остаётся сверху, а в значении «Выбрано: N» и крестик очистки.
- `components/checkbox.css`: чекбокс 20×20, рамка 2px, радиус 6px; отмеченный `#005bff` без рамки, галочка маской SVG; также indeterminate и disabled (opacity 50%).
- `components/calendar.css`: календарь периода. Подложка диапазона `rgba(171,188,213,.118)`, края диапазона `#005bff` (hover `#0050e0`), текст `#f5f7fa`, выходные `#d80e6f`, будущие даты `opacity .5` и зачёркнуты, пресеты `#005bff` 13px.
- `components/demo.html`: страница с примерами (запуск: `python3 -m http.server` из папки `design` и открыть `/components/demo.html`). Сверка с оригиналом: список совпал, календарь 681×318 против 679×318.
