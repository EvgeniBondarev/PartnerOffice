# Правила проекта

## Поиск

Все поля поиска по спискам должны обновлять результаты автоматически при вводе и
очистке, без обязательного нажатия «Найти». Используйте короткую задержку для
уменьшения числа запросов и отменяйте устаревшие запросы. При вводе показывайте
подсказки по подходящим данным; выбор подсказки должен применять поиск. Учитывайте
доступ пользователя на сервере, поддерживайте работу с клавиатуры и сохраняйте
возможность явно применить поиск через Enter или кнопку. Не показывайте подсказки
из данных, которые пользователю не разрешено видеть.
